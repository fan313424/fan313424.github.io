01

财大优选

校园全栈电商系统 · 后端开发

2026.01 — 2026.03

面向云南财经大学的品质生活购物平台，覆盖 PC 商城、移动端管理后台与 AI 智能客服。商城包含商品检索、购物车、下单与订单追踪完整闭环，14 个页面全部原生手写。

交易一致性

结算幂等 + 原子库存扣减

针对重复提交与并发超卖风险，设计 requestId + 数据库唯一索引的结算幂等方案，并通过带库存条件的原子 SQL 扣减库存；结合 Spring 事务保证订单、库存、订单明细与购物车一致，取消订单自动回补库存。

缓存与查询

Redis Cache-Aside + 批量查询

高频商品详情引入 Redis Cache-Aside，采用 30～35 分钟随机 TTL，并在商品更新、删除及上下架后主动失效；购物车和订单明细改为批量查询，补充状态分类与用户订单时间组合索引，缓存不可用时自动降级查库。

知识增强

RAG + Function Calling 双通路

针对工作室私域非结构化文档构建 RAG 检索增强链路；同时通过 @Tool 将项目详情、订单信息和配送状态封装为工具函数，由模型按意图实时查库，补足 RAG 对动态结构化数据覆盖不足的问题。

会话稳定性

Redis 记忆 + 用户级限流

基于 Redis 持久化每用户多轮对话上下文，解决服务重启或多实例部署下的记忆丢失问题；结合用户维度滑动窗口限流，防止 API Key 被恶意消耗，保障高并发下的响应稳定性。
